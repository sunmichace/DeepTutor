# 面试资料标签规范

## 用途

统一面试资料入库时的标签体系，确保所有资料可被题型、岗位、难度、内容类型等维度检索。

## 标签分类

### 1. 内容类型 (content_type)

| 类型 | 说明 | 示例 |
|------|------|------|
| 真题 | 往年考试真题 | 广东事业面试真题 |
| 高分作答 | 高分学员答题、示范作答 | 95分学员录音、示范作答50例 |
| 方法论 | 答题方法、技巧、框架 | 老夏说面试、专项课程 |
| 热点材料 | 时政热点、政策解读 | 热点押题、热门考点汇编 |
| 论证素材 | 论据、案例、名言 | 论证素材100页 |
| 示范表达 | 标准表达、亮点点拨 | 亮点合集 |
| 岗位素材 | 特定岗位相关材料 | 税务/公安专项 |
| 评分标准 | 评分 rubrics、评分规则 | 评分标准说明 |

### 2. 题型 (question_type)

| 题型 | 说明 |
|------|------|
| 综合分析 | 社会现象、观点理解、名言警句 |
| 计划组织 | 活动策划、调研、宣传 |
| 应急应变 | 突发事件处理 |
| 人际沟通 | 人际关系处理 |
| 岗位匹配 | 自我认知、岗位理解 |
| 情景模拟 | 现场模拟类 |
| 无领导小组 | 无领导讨论 |
| 演讲 | 即兴演讲 |
| 通用 | 通用于多个题型 |

### 3. 岗位方向 (position)

| 岗位 | 说明 |
|------|------|
| 综合管理 | 通用管理岗 |
| 税务 | 税务系统 |
| 公安 | 公安系统 |
| 教师岗 | 教育系统 |
| 医疗岗 | 医疗卫生 |
| 基层 | 乡镇/基层 |
| 执法 | 执法岗位 |
| 通用 | 不限岗位 |

### 4. 难度 (difficulty)

- easy: 基础题，适合新手
- medium: 中等难度，常规题型
- hard: 难题，需要深度分析

### 5. 评分维度 (rubric_dimension)

用于标记资料相关的评分维度：
- 审题与立意
- 结构化表达
- 逻辑完整性
- 论据与案例质量
- 岗位匹配度
- 语言自然度
- 临场应对
- 追问应答质量

## 资料清单

### Interview Bank (真题库)
- 2019-2023年广东事业单位面试试题
- 广东选调面试小班带练课(第1-4套)
- 面试真题200例(上下)

### High Score Answer Bank (高分作答库)
- 结构化面试经典试题示范作答50例
- 广东事业单位面试试题示范答题
- 95分以上学员面试答题录音(7套，需转写)

### Methodology Bank (方法论库)
- 老夏30道母题、50母题、100真题
- 老夏说公务员面试
- 17讲课堂笔记(领导演讲/社会现象/名言警句/等)
- 亮点合集

### Argumentation Bank (论证素材库)
- 论证逻辑(必背)
- 论证素材总结(必背)
- 结构化经典论证素材100页

### Hot Topic Bank (热点素材库)
- 结构化面试热门考点汇编200页
- 热点押题(含山东省情)

### High Score Notes (高分笔记库)
- 高分学员笔记及评论文章
- 往年上岸前辈高分面试经验

## 标签使用规则

1. **每条资料至少标记 content_type + position**
2. **真题/方法论类必须标记 question_type**
3. **评分维度为可选标记，作为评分系统的辅助参考**
4. **标签值统一使用中文（岗位类型、题型名）**
