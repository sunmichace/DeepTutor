### 3.4 学习者画像（DynamicProfile）✅

新增字段：

- `repeated_weak_dimensions`：仍弱的维度（≥2 历史低分 + 最新 < 6）
- `resolved_dimensions`：已回暖的旧弱项（最新 ≥ 6）
- `dimension_trends`：improving / declining / persistently_weak / stable
- `training_suggestion_history`：每条带 `status: active | expired`（最新 active，余皆 expired）
- `recent_weak_types`、`recent_trend`、`current_training_suggestion`

算法核心：`_repeated_and_resolved_dimensions` 按时间序识别弱项是否回暖。

### 3.5 抽题策略 v1（picker）✅

`deeptutor/agents/interview/picker.py`：

- `PickerHints`：focus_dimensions / focus_question_types / avoid_question_types / active_suggestion / suggested_difficulty / reason
- `resolve_picker_hints`：从 profile + recent_sessions 派生 hints；难度递进按最近 3 场均分（≥70 → hard，≤50 → easy）
- `build_query_with_hints`：把焦点维度名 + 训练建议片段拼进 RAG query
- `filter_and_rerank`：基于 manifest 标签做软重排（focus +0.15，difficulty 匹配 +0.10，avoid -0.20，原 score 做 tie-breaker）

coordinator 接入：

- `_select_question` 现在返回 `(question_text, picker_snapshot)` 二元组
- `picker_hints` 日志在 `rag_provenance` 之前
- `rag_provenance` 在 rerank 之**后**（验收时被端到端测试抓住并修正）
- `InterviewSession.picker_snapshot` 持久化决策（hints / query / 重排 top-5 / source_kind / effective_difficulty）

> **2026-05-15 live 验证发现并修复**：项目里有**两个** `InterviewSession` 数据类（`agents/interview/models.py` 和 `services/interview/models.py`），picker_snapshot 字段最初只加在前者。memory service 用的是后者，所以 `save_session()` 写盘时整个 picker_snapshot 字段被静默丢弃——active_session 文件里有，sessions/ 持久化文件里 key 都不存在。fix(interview) commit `7ab85e9` 修复：services/interview 类同步加字段；新增 2 条 service-level 回归测试覆盖 save→read 真实路径；live 跑一场新 mock interview 验证 `audit_picker_decisions.py snapshot_coverage 1/1`，整条链路 picker → coordinator → save_session → audit 全程打通。
