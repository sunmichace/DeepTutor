## 当前主要问题

### 1. 还缺一次最新代码后的 live CLI 复验

虽然 `mock_interview` CLI 主链路已经真实跑通过，但在评分归一化、训练建议 fallback、embedding CPU fallback 等补丁之后，还需要再跑一次 fresh live session。

这一步要确认：

- `interview start` 仍能从 `interview_bank` 命中真实资料。
- 生成题目仍是简洁题目，不是长素材。
- `interview answer` 能恢复同一显式 session。
- live DeepSeek 返回不完整 JSON 时，最终评分仍输出 8 个维度。
- `profile` 能看到本次会话写入后的结果。

### 2. DeepSeek live 输出仍有格式波动和截断风险

当前代码已经做了兜底：

- JSON 解析失败时会重试。
- 缺失维度会补齐。
- LLM 调用失败时会启发式评分。
- 训练建议缺失时会从最低分维度生成。

但 live 模型仍可能出现：

- 输出不是严格 JSON。
- 只返回部分评分维度。
- 复盘报告过长导致尾部截断。
- 训练建议夹在 Markdown 表格或标题附近，提取不稳定。

短期可以继续用解析和 fallback 抗住；中期更合理的方案是把训练建议从复盘长文中拆成独立结构化字段。

### 3. 资料质量问题仍存在

资料管线已经能处理 PDF、PPTX、DOCX、旧 DOC，但仍有文件质量问题：

- 4 个 `.pptx` 实际是加密 CDFV2 文件，不是普通 PPTX zip 包。
- 部分 PDF 抽取为空。
- 部分 PDF 报加密或 document closed 相关异常。

这些不是当前 embedding 或 RAG 主链路 blocker，但会影响知识库覆盖率。

### 4. 画像与训练建议还偏工程化

当前 profile 能写入，训练建议也有 fallback，但更像“流程记录 + 单次建议”，还不是稳定的长期训练画像。

后续需要让画像能表达：

- 高频薄弱维度
- 最近几次趋势
- 推荐训练主题
- 已改善项
- 下一次面试优先追问方向

### 5. 当前工作区有大量未提交改动

当前工作区是 dirty 状态，且包含后端、CLI、数据、测试，以及此前遗留的前端/API 文件变更。

后续执行时必须继续遵守：

- 不碰前端和 API 相关文件。
- 不回滚用户或历史改动。
- 只在后端 / CLI / 数据范围内继续收口。
- 每次验证都记录命令和结果。
