## 不做的事

- **不用 `git add -A` / `git add .`**：本轮已经产生过 `=1.1.0` 这种意外文件，`-A` 会把它加回去。
- **不合并 commit D 和 E**：interview 算法改动和脚本工具链解耦，出问题时 `git revert` 更精准。
- **不 amend**：本轮仓库卫生差，amend 会把多主题 diff 继续糅合。
- **不 push --force 到 main**。
