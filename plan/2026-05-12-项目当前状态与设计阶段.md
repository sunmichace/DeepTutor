# DeepTutor 项目当前状态与设计阶段

更新时间：2026-05-12

## 结论

当前项目已经不处在“最初设计方案阶段”，而是处在：

```text
V1 后端闭环已经完成，正在做真实资料、RAG、OCR、长期画像和画像评测的质量收口。
```

也就是说，项目目前的重点不是继续讨论架构能不能成立，而是把已经跑通的后端链路变成稳定、可复用、可持续扩展的数据和训练系统。

当前继续放弃以下范围：

- 前端
- 产品 API
- WebSocket
- Playground 页面
- 前后端联动

这里的“产品 API”指 DeepTutor 自身的 Web/API 层，不包括当前已经确定使用的 DeepSeek LLM API。

当前只关注以下范围：

- 后端能力
- CLI
- mock interview
- RAG
- embedding
- 面试资料入库
- OCR 衍生资料
- 画像和训练建议
- 画像质量评测
- 测试验证

## 当前执行到哪里

### 1. Mock Interview 主链路已跑通

当前 `mock_interview` 后端和 CLI 主链路已经可用。

已验证流程：

```text
interview start -> interview answer -> interview profile
```

已经完成的能力：

- 开始一场模拟面试。
- 从 `interview_bank` 检索资料并生成题目。
- 用户提交答案。
- LLM 评分。
- 生成复盘。
- 生成训练建议。
- 写入用户 profile。
- 清理 active session。

已修复的关键问题：

- CLI 显式 session id 可以贯穿完整流程。
- RAG 长原文不会直接暴露成面试题。
- 评分稳定归一到 8 个 rubric 维度。
- 总分会按 8 个维度重新汇总。
- 训练建议不会再误抓截断标题，例如 `**评估结果`。
- LLM 超时和异常有兜底。

当前判断：

```text
模拟面试已经从“能否实现”进入“如何提升稳定性和训练质量”阶段。
```

## 下一步执行计划

下一步不应推进知识图谱，也不应先做 profile 驱动抽题。当前真正的主线是：

```text
先修数据结构化底座，再扩 OCR 覆盖，再补画像评测，最后再接抽题策略。
```

### 第 1 轮：基础卫生和范围收口

1. 保持 `pytest tests/ --collect-only` 可通过，避免再出现同名测试模块冲突。
2. 明确产品 API / Playground 修改不进入当前主线；若继续坚持放弃前端/产品 API，则这两处只保留为待处理脏变更，不继续开发。
3. 将当前 66 条工作区变更按主题拆分记录：基础测试修复、embedding/RAG、OCR/ingest、mock interview/profile、out-of-scope 前端/产品 API。
4. 对 `scripts/ingest_interview_data.py` 的大规模改动补足标签规则测试，避免后续数据治理没有回归保护。

### 第 2 轮：数据基底收口

1. 新增或完善 manifest 标签审计入口，输出字段覆盖率、默认值占比、OCR 衍生资料标签缺口。
2. 增强 `scripts/ingest_interview_data.py` 的确定性标签规则。
3. 先用文件名 / 路径规则补题型、岗位、难度、热点主题，不依赖 LLM。
4. 对规则无法覆盖的资料，再考虑 DeepSeek 批量辅助打标；必须加离线缓存，避免每次重跑都重新请求 API。
5. 做不少于 10% 的人工抽检，把抽检结果写回本文档。
6. 让 OCR 衍生资料继承来源 PDF 的标签，并允许页段级覆盖。
7. 标签规则稳定后，再运行 `scripts/ocr_interview_pdfs.py` 小批量处理剩余高价值空文本 / 低文本 PDF。
8. 更新本文档中的标签覆盖率。

优先补的标签：

- `estimated_question_type`
- `estimated_position`
- `estimated_difficulty`
- `estimated_content_type`
- `topic_tags`

### 第 3 轮：质量层收口

1. 扩充 `tests/fixtures/profile_eval_cases.json`，目标至少 `8` 条 fixture。
2. profile eval 至少覆盖：偶然失误过滤、持续薄弱识别、持续改善判定、建议过期、多用户隔离。
3. 将 training suggestion 改为结构化输出，优先使用 Pydantic schema 做后处理校验和异常修正。
